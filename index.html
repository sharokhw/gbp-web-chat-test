GBP Web Chat — Test Harness

A blank page for testing the Agentforce Enhanced Chat widget outside of Salesforce. Open this page in a browser and the chat launcher should appear in the corner.

Environment: gbcfullsb · Channel: GBP_WebChat_Channel

What to check

  • The chat launcher appears within a few seconds of the page loading
  • Clicking it opens the conversation window with no pre-chat form
  • Messages send and the agent responds without errors
  • Escalation to a human queue behaves as expected when triggered
  • The window behaves normally on both desktop and mobile screen widths

This is a sandbox build. Nothing here is customer-facing. Note anything unexpected (errors, slow load, layout issues) and pass it back to the project lead.
